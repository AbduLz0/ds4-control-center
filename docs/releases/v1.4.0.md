# DS4 Control Center v1.4.0

Released 2026-10-24. This release follows GitHub tag v1.3.0 and aligns the application version with the release numbering (the upgrade initially used the internal number 0.4.0).

## New features

- Unified Steam, Lutris, desktop-shortcut and manually added game library, with source filters, launching and per-game dead-zone profiles.
- Optional virtual Xbox 360 controller through Linux uinput, with physical-controller reservation and button, stick, trigger and D-pad forwarding.
- Keyboard and mouse mapping for eighteen controller inputs, four presets, rebinding, mouse look, sensitivity, dead zones and trigger tuning.
- Optional, explicitly confirmed uinput permission helper and expanded troubleshooting.
- Updated settings persistence, responsive layouts and documentation screenshots.

## Release review fixes

- Fixed virtual trigger buttons remaining held after multiple analog pressure updates.
- Made repeated controller-reservation requests idempotent, preventing false grab errors.
- Prevented a blocked keyboard mapper from reserving the physical controller at startup.
- Corrected the documented uinput-removal command; the helper must run as the normal user.

## Validation

- 129 backend tests passed with ResourceWarning treated as an error.
- Browser UI smoke suite passed with zero failures, including mapping, game sources, rebinding, profiles, responsive layout and no-bridge behavior.
- JavaScript syntax, shell syntax and Git whitespace checks passed.
- Documentation images use the real frontend and simulated test data, clearly labeled in the gallery.

## Known limitations

Physical DualShock 4 input, real uinput creation and recognition inside games were not verified during release review. The virtual controller does not forward force feedback, motion or touch gestures. Keyboard/mouse output follows window focus; compatibility with games and anti-cheat varies. Per-game profiles adjust the diagnostic dead-zone guide, not keyboard bindings.

Run `./scripts/enable-uinput.sh` as your normal user if you want virtual-input support, then follow its permission instructions. The app does not install these system changes automatically.
