Put a DualShock 4 in pairing mode

  1. Turn the controller off, then hold Share and the PS button together.
  2. Release when the light bar flashes rapidly (two quick blinks).
  3. Press Scan for devices and pick “Wireless Controller”.
  4. If pairing fails, use Forget on any old entry and try again.

For games that only look for an Xbox controller, including many older, Wine and non-Steam titles.

Data and permissions

Settings live in ~/.config/ds4-control-center/settings.json. The app never needs root and never edits system configuration. Virtual keyboard, mouse and Xbox pad output need access to /dev/uinput; the optional scripts/enable-uinput.sh adds a udev rule with your consent.

Enable virtual input
Keyboard/mouse mode and the virtual Xbox pad create devices through /dev/uinput. On most distributions only root can do that by default.

  
Run this once from this project folder. It asks for sudo, adds one udev rule and loads the uinput module. It changes nothing else.

  
sudo ./scripts/enable-uinput.sh

  
  1. Run the command above.
  2. Log out and back in (or reboot) so the new rule applies.
  3. Return here and switch the feature on again.

  
This app never runs sudo or edits system files by itself. If you prefer not to change system permissions, use the virtual Xbox pad only when your user already has access, or remap the controller in the game itself.
